# CR News Radar (public copy)

A read-only copy of CreativeRace's weekly News Radar.

- `index.html` – the page
- `data.json` – the editions, key dates and sector map the page reads

## Publish on GitHub Pages
1. Create a new repository on github.com (e.g. `cr-news-radar`).
2. Upload `index.html`, `data.json` and this README (Add file > Upload files > Commit).
3. Settings > Pages > Build and deployment: Source "Deploy from a branch", Branch `main`, folder `/ (root)` > Save.
4. After a minute the site is live at `https://<your-username>.github.io/cr-news-radar/`.

## Weekly updates
Replace `data.json` with the new export each week (Add file > Upload files, same name, Commit).
The page tells search engines not to index it, but anyone with the link can see it.
